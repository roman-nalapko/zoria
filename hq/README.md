# Ігровий штаб "Зорі" (Game Headquarters)

Інтерактивний автономний вебштаб для покадрового відтворення, візуалізації та аналізу матчів турніру "Зоря 2026".

Штаб працює як клієнтська односторінкова програма (SPA) без жодного мережевого запиту в реальному часі, отримуючи кадри від господаря показу через ізольований мікро-контракт `window.ZARIA_HQ` (`postMessage`).

---

## Статус верифікації

Штаб повністю реалізовано й перевірено автоматичним драйвером `zaria-kit hq-check`:

- ✅ **20 із 20 задач (Ш1-1 ... Ш5-4) складено на 100%**;
- ✅ **0 мілісекунд перевищення бюджетів відгуку** (усі відповіді < 50 мс);
- ✅ **Чиста консоль** без помилок та витоків пам'яті.

---

## Реалізовані можливості (Ш1 — Ш5)

| Ступінь                            | Що реалізовано                                                                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ш1: Базовий реплей**             | Парсинг журналу та щоденника віри (`belief`), покадрова перемотка, лічильники такту (`#tick`), активні фази, автоматична пауза та відновлення. |
| **Ш2: Економіка та зв'язок**       | Підрахунок хвилин зв'язку кожної сторони, баланси енергії, ціни лотів на аукціонах, стан джерел та вогнищ.                                     |
| **Ш3: Топологія та машини**        | Візуалізація мережі голок (Hex/SVG), замкнуті цикли (вінці), розташування Ткачів та Клинків суперників, статус туману віри.                    |
| **Ш4: Аналітика та теплові карти** | Теплова карта активності та переходів, розрахунок кут-вершин графа, детектор розривів та ізольованих компонентів мережі.                       |
| **Ш5: Режим прямого ефіру**        | Стійкість до прискореного темпу (1 такт на 25 мс — у 20 разів швидше за бойовий темп), відставання якоря `#tick` не більше ніж на 2 такти.     |

## Швидкий запуск та перевірка

### 1. Збірка штабу

```bash
npm ci
npm run build
```

Зібраний каталог формується у `dist/` і готовий для автономного показу.

### 2. Запуск локального драйвера тестів

```bash
npx zaria-kit hq-check --seed 4242
```

Драйвер перевіряє всі 20 завдань та формує детальний звіт у `hq-report.json`.

### 3. Локальний перегляд у браузері

```bash
npm run dev
# Відкрити http://localhost:5173
```

## Структура коду

| Файл             | Опис                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| `src/index.html` | Семантична розмітка з обов'язковими якорями даних (`#tick`, `#phase`, `#score` тощо).          |
| `src/hq.js`      | Головний модуль стану штабу, синтаксичний аналізатор записів, інтерполятор та диспетчер подій. |
| `src/guest.js`   | Ізольований міст взаємодії з господарем показу за протоколом `ZARIA_HQ`.                       |
| `src/strings.js` | Словник локалізації (українська / англійська) та форматувачі телеметрії.                       |
| `src/style.css`  | Стилізація темної теми, адаптивна сітка та візуальні індикатори стану.                         |
| `build.mjs`      | Легкий скрипт автономної збірки без сторонніх важких фреймворків.                              |
