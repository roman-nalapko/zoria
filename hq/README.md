# Штаб "Зорі": заготовка показу

Показ - другий вхід вашого застосунку. Кабінет ходить в API мережі HTTPS;
показ відкривають без мережі - у нас на прийманні, на трансляції і у вас
локально під драйвером. Дані йому подає господар показу.

Що вже працює:

- розмова з господарем (`src/guest.js`) - обгортка `window.ZARIA_HQ`;
- всі якорі контракту в розмітці і всі органи під рукою драйвера;
- збірка каталогу `dist` командою `npm run build` без жодної залежності;
- чиста консоль за прогін драйвера.

Чого немає - можливостей Ш1 ... Ш5. Якорі значень стоять порожні: порожнє
значення за контрактом означає "нема чого показати". Порахувати ці значення
за записом і покласти їх у ті самі якорі - ваша робота; вигляд штабу вільний.

## Перевірити у себе

```sh
npm install
npm run build
npx zaria-kit records                 # еталонний запис і пара пресетів
npx zaria-kit hq-check --seed 4242    # той самий драйвер, що на прийманні
```

Звіт ляже у `hq-report.json`: яка задача, яка відповідь, скільки
мілісекунд, який ключ. Ганяти його можна скільки завгодно.

## Де що лежить

| Файл | Що в ньому |
|---|---|
| `src/index.html` | розмітка: якорі значень і органи керування |
| `src/hq.js` | пуск, розбір подачі господаря, органи |
| `src/guest.js` | обгортка господаря показу - копія з кита, правити не треба |
| `src/strings.js` | рядки двома мовами: мову подає господар |
| `build.mjs` | збірка каталогу показу; свій збирач ставиться сюди |

## Свій збирач

Показ зобов'язаний бути каталогом з `index.html`, оголошеним полем
`zaria.hq` у `package.json`, і відкриватися без жодного запиту в мережу. Чим
ви його збираєте - ваша справа: ставте vite, esbuild або що завгодно,
міняйте `build.mjs` і `zaria.hq` на свій каталог збірки.
