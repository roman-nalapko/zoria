# Турнірний бот "Зорі" (Champion AI Bot)

Автономний агент для гри в реальному часі за протоколом "Зорі" (500 мс на такт).

Бот виступає основним ігровим клієнтом команди, реалізуючи графову стратегію розширення, контроль рою, координацію аукціонів та стійкість до збоїв.

---

## Стратегія Champion (`src/strategy.ts`)

| Компонент                           | Як влаштовано                                                                                                                                                                                                                                                                     |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Вінцевий цикл (Crown Cycle)**     | Алгоритмічний пошук DFS у локальному графі світу для знаходження мінімального замкненого 6-вершинного циклу, підключеного до стартової голки. Пріоритетне замикання циклу активує постійний множник $+15\%$ ($x1.15$) на всі наступні очки партії.                                |
| **Склад рою (Squad Composition)**   | Суворий ліміт сумарної ваги рою у 8 одиниць: рівно 3 Ткачі ($3 \times 2 = 6$) та 2 Клинки ($2 \times 1 = 2$). Розподіл ролей: один Клинок-Вартовий (Sentinel — оборона бази та кут-вершин графа від диверсантів), один Клинок-Мисливець (Hunter — полювання на Ткачів суперника). |
| **Аукціонний блок (Auctions)**      | Динамічні ставки з порогом 71 енергії лише на ті лоти, що знаходяться на відстані $\le 8$ від бази або $\le 5$ від запалених голок, запобігаючи розпорошенню енергії на ізольовані голки.                                                                                         |
| **Навігація та рух (Routing)**      | Пошук найкоротших шляхів через алгоритм Дейкстри / A* з урахуванням вартості руху через туман та випереджального перехоплення ворожих траєкторій.                                                                                                                                 |
| **Резервна грамота (`nakaz.yaml`)** | Автономний офлайн-наказ із профілем активної експансії, що виконується сервером у разі фізичного розриву зв'язку або `SIGKILL` процесу.                                                                                                                                           |

## Результати перевірок та турніру

- **Груповий етап**: 2-е місце у Групі 6, **22 із 24 очок** (Match 1: 8, Match 2: 8, Match 3: 6).
- **Надійність K1**: **0 дефектів у всіх 9 партіях** (0 відмов присяги, 0 перевищень ваги рою, 0 неконтрольованих тактів наказу).
- **Провокатор (K2)**: Рівень 3 пройдено на 100% (9 з 9 перемог під час відключень сокета та примусових `SIGKILL`).

## Службовий порт (`src/status.ts`)

Змінна середовища `STATUS_PORT=7811` вмикає внутрішній HTTP-порт бота:

- `GET /state` — поточний знімок стану проводу (номер такту, кадри, лічильники помилок, щоденник віри);
- `POST /preset` — зміна пресету поведінки між партіями.

Цей ендпоінт опитується контейнером `control-plane` для формування канонічних метрик `/health` та `/metrics`.
