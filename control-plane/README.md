# Control Plane Microservice

Службовий мікросервіс площини керування для турнірного бота "Зорі".

Забезпечує зовнішнє спостереження, моніторинг готовності та збір метрик для Docker-стека й автоматичного тестувальника організаторів (`zaria-kit preflight`).

---

## Архітектурна ізоляція

Сервіс не має власного стану гри і побудований на стандартній бібліотеці `node:http` без зовнішніх залежностей. Стан запитується динамічно з внутрішнього порту бота (`STATUS_PORT: 7811`, `GET /state`) через ізольовану мережу Docker. Це гарантує:

- Бот продовжує автономну гру навіть у разі перезапуску `control-plane`;
- Читачі потоку подій (`/belief-stream`) обслуговуються окремим процесом, не навантажуючи петлю такту бота.

---

## Ендпоінти

| Метод  | Шлях               | Опис                                                                                   |
| ------ | ------------------ | -------------------------------------------------------------------------------------- |
| `GET`  | `/health`          | Перевірка готовності стека (`200 OK` або `503 Service Unavailable`).                   |
| `GET`  | `/metrics`         | Метрики у форматі Prometheus (лічильники такту, кадрів, запитів, помилок).             |
| `POST` | `/presets/promote` | Перемикання стратегії між партіями (`200 OK`; під час активного бою — `409 Conflict`). |
| `GET`  | `/belief-stream`   | Server-Sent Events (SSE) трансляція щоденника віри бота в реальному часі.              |
| `GET`  | `/livez`           | Базова перевірка працездатності HTTP-процесу.                                          |
| `GET`  | `/presets`         | Список доступних стратегічних пресетів.                                                |

---

## Конфігурація через змінні середовища

| Змінна            | За замовчуванням        | Опис                                                |
| ----------------- | ----------------------- | --------------------------------------------------- |
| `PORT`            | `7801`                  | Порт прослуховування мікросервісу.                  |
| `HOST`            | `0.0.0.0`               | Мережевий інтерфейс.                                |
| `HEAD_URL`        | `http://127.0.0.1:7811` | Внутрішня адреса голови бота (`bot/src/status.ts`). |
| `HEAD_TIMEOUT_MS` | `1000`                  | Таймаут опитування голови бота.                     |
| `ZARIA_BELIEF`    | `/data/belief.ndjson`   | Шлях до щоденника віри на спільному Docker-томі.    |

---

## Локальний запуск

```bash
cd control-plane
npm start
```

Або у складі повного Docker Compose стека:

```bash
docker compose up control-plane
```
